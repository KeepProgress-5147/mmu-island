4. 執行成果：puma.taipei/heart-island 網站技術深度分析報告

4.1 網站定位與設計概念

「HEART 政策島」 是台北市長參選人沈伯洋（Puma）推出的 3D 互動政見平台。設計致敬經典桌遊《卡坦島 (Catan)》，將台北市輪廓轉化為 14 個等大六邊形（Hexagonal Grid）政策島，在島上放置 94 座政策細項微縮建築模型 與 20 條跨政策協作線（Flows），並以 HEART 五大維度（Habitat 空間、Empower 培力、Accompany 陪伴、Resilience 韌性、Time 時間）串聯城市治理藍圖。

4.2 系統架構圖 (System Architecture)

4.3 八大核心技術亮點深度拆解

01 原生 ES Modules + Import Map 無打包架構

不依賴 React、Vue 等前端框架，亦未使用 Webpack/Vite 打包混淆，直接透過瀏覽器原生 <script type="importmap"> 載入自託管的 Three.js r160 與 11 支模組化 Vanilla JS 檔案。全站無外部 3D 模型檔，核心程式碼與 JSON 僅約 600 KB，首屏載入極快。

02 100% 純程式碼程序化 3D 建模與 InstancedMesh

全場 94 座微縮建築（如市政大樓、圓頂研究館、貓空纜車、A 字木屋、伙房照護站）完全不載入任何 .gltf / .glb 模型，而是由 kit.js 定義 16 種基礎幾何體，收集全場景數萬個零件後按幾何種類合併為單一 THREE.InstancedMesh 批次繪製，並透過 polygonOffset 與微米級確定性尺寸抖動消除 Z-Fighting 共面閃爍。

03 六角軸座標系與 Canvas 2D 程序化材質貼圖

world.js 採用尖頂六邊形軸座標 axialToWorld(q, r) 排列出台北市輪廓。地面材質與 3D 建築中文立牌不載入外部圖片，而是使用 HTML5 2D <canvas> 搭配確定性亂數 mulberry(seed) 即時繪製 14 種地面紋理（花崗岩、跑道、農田、軟墊、木棧道等）並轉為 THREE.CanvasTexture。

04 SimplexNoise 台北盆地地形與客製化 GLSL Shaders

environment.js 以 SimplexNoise + FBM 結合北側七星山、西側觀音山、東側四獸山、南側貓空梯田等控制點生成環場盆地，並自動壓低鏡頭正前方山勢。內建三大自訂 ShaderMaterial：星空大氣穹頂 Shader、fwidth() 導數抗鋸齒水波 Shader，以及依政見證據等級動態裁切實線/虛線脈衝的 協作線光管 Shader。

05 Q 版市民尋路、彩蛋 Puma 與離屏渲染縮圖

people.js 建立跨島環狀步道連通圖（Walkway Graph），驅動 14 種市民角色手持道具在政策島間走動交接，並觸發「城市日誌」LIVE 事件。內建彩蛋角色 Puma（沈伯洋） 依序巡迴 14 島並站上肥皂箱揮手。點擊建築或小人時，系統透過 160×160 (4x MSAA) 的 THREE.WebGLRenderTarget 即時離屏拍攝 3D 特寫並轉為 JPEG DataURL 顯示。

06 CSS2DRenderer 混合排版與智慧防重疊演算法

透過 CSS2DRenderer 將 HTML 標籤錨定於 3D 座標。app.js 內的 clipLabels() 每幀計算所有標籤與 UI 面板的碰撞框：若重疊則自動嘗試 7 向微幅位移 ➔ 縮合為純數字徽章（.mini）➔ 滑出面板邊緣（.slid），並導入 8px 遲滯緩衝（Hysteresis） 徹底防止標籤在臨界位置閃爍跳動。

07 社群共創模組注入：heart-me.js 自訂紙娃娃

收錄自開發者 readper 的開源專案。透過包裝 THREE.Scene/Camera.prototype.updateMatrixWorld 無侵入式攔截場景實例；從 89 條行人路線逆向重建導航路網；並利用 JS Generator (function* computeFitSpot) 分幀執行上千條 Raycast。支援高度自訂角色外觀（存於 localStorage）及召喚分身 Puma 雙人羅盤定點合照。

08 24h 日夜光影、無障礙設計與工程級 QA 介面

【步驟 2】在網頁點擊上傳檔案功能

10.6 部署常見問題與排查技巧 (FAQ)

  • Q1：網頁開啟後 3D 畫面出不來或一片黑？
    請檢查根目錄是否有 vendor/three-bundle.js。若使用網頁拖曳上傳，請務必確認 vendor 資料夾有成功上傳（不能只有把 three-bundle.js 丟在根目錄，必須在 vendor/ 子目錄內）。
  • Q2：GitHub Pages 出現 404 Not Found？
    GitHub Pages 部署通常需要 1 到 2 分鐘排程發布。如果剛按下 Save，請稍等約 60 秒後再重新整理，看到「Your site is live at...」的綠色勾勾提示後再開啟。
  • Q3：未來如果要更新島上的建築或最新消息怎麼辦？
    指令方式：本地修改 mmu-data.js 或 mmu-app.js 後，執行 git commit -am "update" 與 git push。
    網頁方式：直接在 GitHub 網頁上找到 mmu-data.js，點擊右上角鉛筆圖示（Edit this file）直接修改文字或新聞，按下 Commit changes，GitHub Pages 就會在 1 分鐘內自動更新全網！
