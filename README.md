# 馬偕醫學大學 3D 互動校園島｜Mackay Medical University 3D Campus Island

[![Three.js](https://img.shields.io/badge/Three.js-r160-black?logo=three.js)](https://threejs.org/)
[![Status](https://img.shields.io/badge/Status-Complete-success)]()
[![License](https://img.shields.io/badge/License-MIT-blue)]()

以 **「桌遊化微縮世界」** 隱喻為核心架構的 3D 互動校園導覽網站。參考 **HEART 政策島** 之輕量化純程式碼程序化建模（Zero-Asset Procedural 3D），為**馬偕醫學大學（MMU，新北市三芝區）**量身打造依山傍海的立體校園入口導覽平台。

---

## ✨ 核心特色與亮點

1. **7 座六邊形主題島嶼 ＆ 27 座高精細微縮建築地標**：
   - `01 醫學院島`：醫學系教學大樓（含大體老師中心採光穹頂）、醫檢暨再生醫學大樓（含雙螺旋 DNA 雕塑）、視光學系臨床中心、生物醫學研究所（含空中連通天橋）。
   - `02 護理學院島`：護理學系大樓、南丁格爾金燈紀念碑、高擬真臨床模擬中心（OSCE，含擬真救護車）、社區健康與偏鄉護理站。
   - `03 厚生健康學院島`：聽語學系大樓（含 9 道聲學波浪鰭片屋頂）、長照所（含療癒溫室花園）、高齡福祉科技所（含樂齡地壺球賽道）、老化感官體驗實驗室。
   - `04 全人與馬偕精神島`：哥德式馬偕精神禮拜堂（含鐘樓尖塔、玫瑰花窗與焚而不燬永恆火炬）、全人教育中心圓頂大廳、數位校史館（淡水牛津學堂中西合璧意象）、治校理念紀念碑。
   - `05 山海生活與宿舍島`：家庭式優質學生宿舍雙塔（含中央交誼廳）、山海景觀玻璃圖書館、多功能活動中心（含拱頂體育館與戶外 PU 跑道球場）、三芝校園交通接駁總站（含 2 輛校園接駁車）。
   - `06 行政與數位校務島`：第一二教研行政大樓（含 7 層中央金冠鐘樓）、教務與學務一站式服務中心、總務與 CSR 綠能中心（太陽能板與風力發電機）、馬偕雲與數位校務中樞（含通訊天線）。
   - `07 招生、醫療體系與國際 USR 島`：招生資訊與 OPEN DAY 歡迎拱門、馬偕紀念醫院醫療體系基地（含屋頂直升機停機坪）、北海岸 USR 偏鄉服務營基地、國際醫療交流碼頭（含紅白條紋燈塔與帆船）。
2. **三芝在地風情：茭白筍（美人腿）景觀造景**：
   - 參考三芝特產茭白筍「潔白圓潤飽滿、修長微彎收尖、半剝開翠綠筍鞘」外型，於每座島嶼中央廣場設置「三芝美人腿」水池花台景觀雕塑座，並於綠地配置「三芝水梯田茭白筍生態造景畦」。
3. **12 座跨島景觀大橋與島內幹道路網**：
   - 實體連通 7 座島嶼的 12 條通道，包含雙深水石造橋墩、微拱柏油路面、金色中央分隔虛線、雙側石柱護欄與橋上路燈，中央 6 座主橋更配有松石綠鋼拱桁架（Arch Truss）。
4. **師生休憩座椅與戶外休閒家具**：
   - 每座島嶼均配置木構藤架涼亭與 L 型軟墊戶外沙發茶几區、露天遮陽傘咖啡圓桌四椅組、草地野餐木桌椅組與帶扶手靠背之公園木長椅。
5. **三芝依山傍海 4 時段光影系統**：
   - 支援 `🌅 清晨`（大屯山晨曦）、`☀️ 白天`（晴空朗朗）、`🌇 三芝夕陽`（海景晚霞）、`🌙 星空`（北海岸星斗與校園窗戶溫暖亮燈）一鍵平滑插值切換。
6. **巡迴 7 島的「馬偕博士 (Dr. MacKay)」彩蛋角色**：
   - 身穿 19 世紀黑色禮服、蓄落腮鬍、頭戴禮帽、手提醫療袋，在校園巡禮；點擊頭頂標籤或右上角按鈕即可跟隨鏡頭並展開歷史故事卡。
7. **訪客身分快速切換 ＆ 整合校務三頁籤面板**：
   - 底部提供 `00 全校總覽`、`01 考生與家長`、`02 在校學生`、`03 教職員與校友` 身分切換，對應島嶼會自動高亮發光並展開專屬入口。
   - 右側側欄提供「校園島嶼 (27)」、「最新消息」與「常用系統與處室」三大頁籤。
8. **零外部 3D 模型、零構建（Zero-Build）架構**：
   - 100% 純原生 JavaScript (ES6+) + Three.js r160，首屏輕量，無須 npm/webpack/vite，支援直接雙擊 `index.html` 或以 GitHub Pages 靜態託管。

## 🚀 本地執行方法

本專案為純靜態網站，無需安裝任何伺服器或編譯工具：
1. 將本專案下載或 Clone 到本機：
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. 直接雙擊 `index.html`，即可在任何現代瀏覽器（Chrome, Edge, Safari, Firefox）中開啟體驗！

---

## 🌐 部署至 GitHub Pages

本專案完全相容 GitHub Pages 免費靜態託管：
1. 在 GitHub 上建立一個新的 Public Repository。
2. 將本專案推送到該 Repository 的 `main` 分支。
3. 進入 Repository 的 **Settings ➔ Pages**：
   - **Source** 選擇 `Deploy from a branch`
   - **Branch** 選擇 `main` / `/(root)`，點擊 **Save**。
4. 約 1~2 分鐘後，即可透過 `https://<your-username>.github.io/<repo-name>/` 在線瀏覽！
